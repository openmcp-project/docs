# Contribution Guidelines

**Anyone is invited to contribute to OpenControlPlane**. You do not need organization membership to do so. 

This page walks you trhough the **essential steps to make you an active contirbutor**!

_For a detailed description, checkout the [org-wide contributing guide](https://github.com/openmcp-project/.github/blob/main/CONTRIBUTING.md)_.

## 1. Bring your suggestions

Changes and fixes are welcome—follow the approach below to help us collaborate effectively.

### New Features
New features are best discussed with maintainers in an issue **before implementing them**. 

:::info Let's meet

We hope to see you at one of our [community calls](https://github.com/orgs/openmcp-project/discussions/categories/community-calls) to meet, and discuss your next contribution idea.

:::

### Bug fixes
For a bug fix or documentation change, link an issue or explain the motivation in your PR 

### Code of conduct

Follow the project's license and [Code of Conduct](https://github.com/openmcp-project/.github/blob/main/CODE_OF_CONDUCT.md). 

Using AI-generated code or content? Read the [AI contribution guidelines](https://github.com/openmcp-project/.github/blob/main/CONTRIBUTING_USING_GENAI.md) first.

## 2. Fork and create a feature branch

:::info Every change must come from fork!

**Every change to a public repo is submitted through a pull request from a fork.**

:::

1. Fork the repo and clone your fork.
2. Create a feature branch from the original repo's default branch.

   <a className="button button--outline button--primary button--sm" href="https://docs.github.com/en/get-started/quickstart/fork-a-repo">Learn how to Fork a Repo</a>

3. Make your changes and push them to your fork.
4. Open a PR from your fork to the original repo.

   <a className="button button--outline button--primary button--sm" href="https://docs.github.com/en/pull-requests/how-tos/create-pull-requests/creating-a-pull-request-from-a-fork">Learn how to open PR from fork</a>

## 4. Open Pull Request from fork

Familiarize yourself with any repos' `README` and `CONTRIBUTING.md` for setup, tests, and repository-specific guidance. 

For any controller change, also checkout our [General Controller Guidelines](/developers/general).

## Access 

### Features and improvements

**You do not need membership to contribute** features and improvements to this project.

### Administration

If you think you should join the organization or a team, [reach out to the maintainers on GitHub Discussions](https://github.com/orgs/openmcp-project/discussions) to discuss the access you need.

All organization settings are managed as code.

- **Members and teams:** [`orgs/openmcp-project/org.yaml`](https://github.com/neonephos/account-administration/blob/main/orgs/openmcp-project/org.yaml). Follow the [administration guide](https://github.com/neonephos/account-administration/blob/main/docs/peribolos-setup.md) to propose changes through a PR.
- **Repository rules and release settings:** [`openmcp-project/admin`](https://github.com/openmcp-project/admin) _(admins-only)_.
